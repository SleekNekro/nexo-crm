# Nexo CRM 0.2.0-beta.3 — ajustes de la instalación local

- La cuenta inicial del asistente local admite contraseñas de **8 a 128 caracteres**.
- Corregida la búsqueda de los gestores de credenciales de Docker al abrir Nexo desde Finder: no hace falta iniciar la aplicación desde una terminal.
- Se mantienen la instalación aislada, los controles Iniciar/Detener/Abrir y la conservación de datos.

Descarga el ZIP de tu Mac (Intel o Apple Silicon) o el instalador Windows x64. Instala y abre Docker Desktop, abre Nexo y elige **Probar en este ordenador**. Elige tu contraseña, pulsa **Preparar mi CRM** y después **Abrir CRM**. El usuario inicial es `developer`.

[Guía de instalación](https://github.com/SleekNekro/nexo-crm/blob/main/docs/desktop-quickstart.md).

Docker Desktop sigue siendo necesario y tiene sus propios requisitos de sistema y licencia. La primera descarga requiere Internet y varios GB libres. Esta instalación solo escucha en el propio ordenador. Android e iPhone se conectan a un servidor HTTPS existente.

Las aplicaciones de escritorio no tienen firma comercial/notarización: revisa las indicaciones de [instalación](https://github.com/SleekNekro/nexo-crm/blob/main/apps/README.md) si el sistema muestra un aviso. No desactives globalmente sus protecciones.

Los archivos incluyen sumas SHA-256. El APK mantiene la firma de las betas anteriores. Proyecto MIT; utiliza datos de prueba durante la evaluación.

Instalación inicial y acceso comprobados manualmente en un Mac Apple Silicon real, con Docker Desktop ya instalado y un entorno equivalente al de Finder. Cuenta conservada tras parada/arranque del proyecto por CLI, sin afectar a otro CRM activo. 182 pruebas web y 11 pruebas Rust superadas; integración del servidor verificada en AMD64 y ARM64. Sigue pendiente la prueba completa de instalación en Windows físico.
