# Nexo Desktop 0.2.0-beta.5

Actualizaciones desde la aplicación para Mac y Windows: **CRM → Conexión, servidor y actualizaciones**.

- Buscar e instalar futuras versiones firmadas del cliente.
- Actualizar el servidor local desde el mismo asistente, con copia de base de datos, fotos y configuración.
- Recuperación de la versión anterior si falla el arranque y botón para retomar una recuperación interrumpida.
- Bloqueo de operaciones concurrentes y de regresiones a servidores anteriores.

Esta versión de escritorio incluye el servidor 0.2.0-beta.4 (creador de módulos y presupuestos personalizados). Android sigue en beta.4. Para habilitar el botón por primera vez hay que instalar beta.5 manualmente. Los servidores remotos no se modifican desde los clientes.

Consulta [la guía de actualización](../desktop-updates.md).
