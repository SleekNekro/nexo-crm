# Nexo CRM 0.2.0-beta.2 — empieza sin programar

Esta beta incorpora un asistente para instalar y gestionar tu servidor local desde la aplicación de Mac o Windows.

## Cómo probarlo

1. Descarga el paquete de tu equipo: Mac Apple Silicon, Mac Intel o Windows x64.
2. Abre Nexo y elige **Probar en este ordenador**.
3. Si falta Docker Desktop, pulsa el botón de descarga, instálalo y ábrelo siguiendo sus indicaciones. En Windows utiliza contenedores Linux.
4. Vuelve a Nexo, pulsa **Comprobar**, elige tu contraseña y pulsa **Preparar mi CRM**.
5. Cuando termine, pulsa **Abrir CRM**. Entra como `developer` con tu contraseña. Dentro puedes elegir empezar vacío o cargar ejemplos ficticios.

La primera instalación requiere Internet y varios GB libres. **No necesitas Git, Python ni una terminal.** Docker Desktop es un requisito externo: puede pedir permisos, WSL2 o reiniciar Windows; revisa sus condiciones de licencia.

[Guía completa](https://github.com/SleekNekro/nexo-crm/blob/main/docs/desktop-quickstart.md).

## Qué incluye

- Instalación independiente con imágenes precompiladas para Intel/AMD y ARM.
- Estado del servidor, progreso y botones **Iniciar**, **Detener** y **Abrir CRM**.
- Contraseña elegida por el usuario; ninguna cuenta existente se sobrescribe.
- Datos conservados al detener y reiniciar. Aislamiento respecto a otros proyectos Docker.
- Opción **Tengo un servidor** para conectar con una instalación existente.
- APK Android firmado para conectarse a un servidor HTTPS existente. iPhone utiliza la PWA.

## Límites y comprobaciones

La instalación guiada escucha solo en este ordenador. Para acceder desde móviles u otros equipos necesitas una instalación de red con HTTPS. Cerrar la aplicación no detiene el servidor. Esta beta conserva la versión de servidor de instalaciones existentes; no incluye actualizaciones automáticas ni una pantalla de copias de seguridad.

182 pruebas web y 9 pruebas Rust; instalación limpia y conservación tras parada/arranque verificadas en AMD64 y ARM64. Las pruebas visuales del asistente utilizan IPC simulado. Sigue pendiente validar todas las interacciones nativas, fotos y PDF en equipos físicos de cada plataforma.

Mac requiere macOS 11 o posterior. Descomprime el ZIP y mueve NEXO CRM a Aplicaciones. No hay notarización Apple: si Gatekeeper lo bloquea, verifica el origen y utiliza Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente. No desactives Gatekeeper globalmente.

Windows x64: ejecuta el instalador. No tiene firma comercial; SmartScreen puede mostrar un aviso. WebView2 puede necesitar Internet durante la instalación.

Android 8+: instala el APK autorizando esa fuente. Es experimental y requiere HTTPS con un certificado de confianza del sistema. Mantiene la firma de la beta anterior para actualizarla.

Comprueba los archivos con `SHA256SUMS.txt`. No se incluyen datos de empresas ni claves privadas. Proyecto abierto bajo licencia MIT; utiliza datos de prueba durante la evaluación.
