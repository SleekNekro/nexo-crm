# Nexo CRM 0.2.0-beta.4 — módulos propios y presupuestos personalizados

## Crear módulos sin programar

Desde **Crear y gestionar módulos**, el desarrollador puede partir de Equipos o crear una sección vacía. Incluye campos de texto, número, importe, fecha, desplegable, casilla y relaciones con empresas/contactos; listado con búsqueda, fichas y permisos de consulta, creación, edición y eliminación por perfil.

Archivar campos o desactivar módulos conserva sus datos. El servidor comprueba permisos, empresa y versiones para evitar sobrescrituras. Kanban, calendario, adjuntos y automatizaciones para módulos propios quedan para próximas versiones. [Alcance y límites](https://github.com/SleekNekro/nexo-crm/blob/main/docs/custom-modules.md).

## Presupuestos con la identidad de tu empresa

Configura logo, colores y datos fiscales/contacto en **Configurar negocio → Identidad**. En **Plantilla de presupuesto**, ajusta validez, condiciones de pago y observaciones al pie, con vista previa. Las revisiones conservan sus ajustes originales. La caducidad respeta la validez elegida. Corregida la carga del logo antes de generar el PDF.

## Navegación más cómoda

**Cerrar sesión** está dentro de **Mi cuenta**. Formularios y fichas tienen botones **Volver**; el documento del presupuesto abre en la misma ventana y permite regresar a su ficha, también desde una PWA.

## Instalación

Descarga el ZIP para Mac Apple Silicon o Intel, o el instalador Windows x64. Con Docker Desktop instalado y abierto, elige **Probar en este ordenador**. El asistente descarga el servidor beta.4; el usuario inicial es `developer` y tú eliges la contraseña. Android e iPhone necesitan un servidor accesible por HTTPS.

**Si ya tienes un servidor instalado:** actualizar la aplicación cliente no sustituye automáticamente las imágenes guardadas del servidor. Haz una copia de seguridad y actualiza las tres imágenes de `compose.yaml` a `app-0.2.0-beta.4`, `pdf-0.2.0-beta.4` y `gateway-0.2.0-beta.4` en `ghcr.io/sleeknekro/nexo-crm`, manteniendo `.env`, nombre del proyecto y volúmenes. Ejecuta `docker compose pull` y `docker compose up -d` desde esa carpeta; nunca `down -v`. La primera apertura crea las tablas adicionales sin borrar las existentes. [Guía local](https://github.com/SleekNekro/nexo-crm/blob/main/docs/desktop-quickstart.md).

Los paquetes de escritorio no están notarizados ni firmados con un certificado comercial. El APK mantiene la firma de las betas anteriores. Se incluyen sumas SHA-256. Código MIT; utiliza datos de prueba durante esta beta.
