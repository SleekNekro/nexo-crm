# Nexo CRM — caso de estudio

## Problema

La gestión comercial y el seguimiento de ejecución suelen repartirse entre contactos, hojas de cálculo y documentos. El objetivo de Nexo es reunir el ciclo completo sin obligar a que cada venta termine en una obra, y mantener una interfaz comprensible para personas con poca experiencia digital.

## Decisiones destacadas

- Crear un presupuesto desde la empresa genera el trato asociado y reduce pasos.
- Separar presupuesto aceptado, pedido y obra permite ventas de suministro.
- Reutilizar una web en escritorio y móvil concentra las reglas en el servidor.
- Separar los datos por espacio y comprobar permisos en API permite diferentes equipos y marcas.
- Mantener revisiones del presupuesto conserva el documento emitido.
- Validar horas antes de incluirlas en costes distingue lo declarado de lo confirmado.

## Qué demuestra el código

Modelado de dominio, React/TypeScript, API Next.js, PostgreSQL, autenticación y autorización, Docker, pruebas automatizadas, integración de impresión y clientes Tauri/Android. Incluye documentación de límites y tareas pendientes.
