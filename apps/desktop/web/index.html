Comprobando Docker…

Primero, Docker Desktop

  1. Instala Docker Desktop desde docker.com/products/docker-desktop.
  2. Ábrelo y espera a que termine de arrancar. En Windows, elige contenedores Linux.
  3. Vuelve aquí y pulsa «Comprobar».

La primera descarga requiere Internet y varios GB libres. Docker puede pedir permisos o reiniciar Windows. Revisa sus condiciones de licencia.
